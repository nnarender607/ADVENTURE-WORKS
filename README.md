# Adventure Works - End-to-End Data Analytics Portfolio Project

A comprehensive, end-to-end Data Analysis project developed during a Data Analyst internship[cite: 1]. This project covers the complete data lifecycle—from raw data cleaning, relational lookups, and SQL operations to interactive dashboard creation and multi-dimensional reporting across **Excel**, **SQL**, **Power BI**, and **Tableau**.
